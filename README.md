# jnum for Ject

Numerical operations for [Ject](https://github.com/riffifi/ject), with a Ject
facade and a Rust native backend. See `src/lib.ject` for the exported API and
`tests/numerics.ject` for working examples.

With Ject 0.11 and Rust installed, clone the repository and run `ject test`
from its root. The package includes its copy of the native SDK.
